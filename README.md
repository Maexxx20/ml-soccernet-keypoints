# Athletes-at-Olympia
Der Datensatz athletes.csv enthält Athletinnen und Athleten aus verschiedenen Wintersportarten. Wichtige Felder sind Name, Geschlecht, Geburtsdatum, Geburtsland, Landeskürzel, Disziplin und Körpergrösse. Für die Modellierung werden insbesondere discipline, country_code, birth_country, height_m sowie birth_year verwendet. Damit lassen sich sinnvolle Zusammenhänge analysieren, weil Sportart, Herkunft und körperliche Merkmale im Datensatz in realem Bezug stehen. Der Datensatz ist strukturiert, gut tabellarisch nutzbar und eignet sich für eine erste Klassifikationsaufgabe im Machine-Learning-Umfeld.
